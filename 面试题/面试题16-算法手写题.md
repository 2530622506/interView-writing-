### No.1 · 两数之和 

> 给定一个整数数组 `nums` 和目标值 `target`，找出两个数使它们相加等于 target，返回它们的下标。

**示例：**
```
输入：nums = [2,7,11,15], target = 9
输出：[0,1]（nums[0] + nums[1] = 9）
```

**解题思路（哈希表）：**
1. 遍历时用 Map 记录"需要的补数 → 当前索引"
2. 遇到 Map 中存在当前数，说明找到了
3. 时间复杂度：O(n)；空间复杂度：O(n)

```js
var twoSum = function(nums, target) {
  const map = new Map()  // 值 → 索引

  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i]
    if (map.has(complement)) {
      return [map.get(complement), i]  // 找到答案
    }
    map.set(nums[i], i)  // 记录当前数
  }
  return []
};
```

**⚠️ 易错点：**
- 先查 Map 再存入，避免用同一个元素两次（如 target=6, nums=[3,3]）
- Map 存的是 `值 → 索引`，不是 `索引 → 值`
- 题目保证有唯一解，可以直接 return 不用收集所有答案

### No.2 · 反转链表 

> 给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**示例：**
```
输入：1 -> 2 -> 3 -> 4 -> 5
输出：5 -> 4 -> 3 -> 2 -> 1
```

**解题思路（迭代）：**
1. 维护 prev（上一个节点）和 curr（当前节点）
2. 每次将 curr.next 指向 prev，然后同步后移
3. 时间复杂度：O(n)；空间复杂度：O(1)

```js
// 迭代版（推荐）
var reverseList = function(head) {
  let prev = null   // 前驱节点，初始为 null（反转后尾节点的 next）
  let curr = head

  while (curr) {
    const next = curr.next  // 保存下一个节点，防止断链
    curr.next = prev        // 反转指针
    prev = curr             // prev 后移
    curr = next             // curr 后移
  }
  return prev  // 循环结束时 curr 为 null，prev 是新头节点
};

// 递归版
var reverseListRecursive = function(head) {
  if (!head || !head.next) return head  // 空链表或单节点直接返回

  const newHead = reverseListRecursive(head.next)  // 递归反转后续节点
  head.next.next = head   // 让后继节点指回当前节点
  head.next = null        // 当前节点成为尾节点
  return newHead
};
```

**⚠️ 易错点：**
- 迭代中必须先保存 `next = curr.next` 再修改 `curr.next`，否则断链找不到下一个节点
- 递归版终止条件是 `!head || !head.next`（空链表也要处理）
- 递归后必须设置 `head.next = null`，否则原来的头节点会形成环

### No.3 · LRU 缓存 

> 设计数据结构，实现最近最少使用（LRU）缓存。get 和 put 操作的时间复杂度都要求 O(1)。

**示例：**
```
LRUCache(2)
put(1, 1) → cache: {1=1}
put(2, 2) → cache: {1=1, 2=2}
get(1)    → 返回 1，cache: {2=2, 1=1}（1 最近使用移到末尾）
put(3, 3) → 淘汰 2，cache: {1=1, 3=3}
get(2)    → 返回 -1（已淘汰）
```

**解题思路（Map 保序）：**
1. JS 的 Map 按插入顺序迭代，keys().next() 是最旧的
2. get 时：删除再重新插入（移到末尾 = 最近使用）
3. put 时：先删再插；若超容量，删除 keys().next()（最久未用）
4. 时间复杂度：O(1)；空间复杂度：O(capacity)

```js
class LRUCache {
  constructor(capacity) {
    this.capacity = capacity
    this.map = new Map()
  }

  get(key) {
    if (!this.map.has(key)) return -1
    const val = this.map.get(key)
    // 删除后重新插入，将其移到 Map 的末尾（最近使用）
    this.map.delete(key)
    this.map.set(key, val)
    return val
  }

  put(key, value) {
    if (this.map.has(key)) this.map.delete(key)  // 先删（更新）
    this.map.set(key, value)
    // 超容量时淘汰最旧的（Map 的第一个 key）
    if (this.map.size > this.capacity) {
      this.map.delete(this.map.keys().next().value)
    }
  }
}
```

**⚠️ 易错点：**
- `map.keys().next().value` 获取 Map 第一个 key，这是最久未使用的
- get 中必须先删再插，纯 set 不会更新顺序
- put 超容量判断在插入之后（先插入再判断，这样新 key 已经在 Map 里了）

### No.4 · 无重复字符的最长子串 

> 给定一个字符串 `s`，找出其中不含重复字符的最长子串的长度。

**示例：**
```
输入：s = "abcabcbb"
输出：3（"abc"）
```

**解题思路（滑动窗口）：**
1. 用 Map 记录字符最近一次出现的索引
2. 左指针 left 在发现重复时跳到重复字符的下一位
3. 每次更新最大长度
4. 时间复杂度：O(n)；空间复杂度：O(min(m,n))

```js
var lengthOfLongestSubstring = function(s) {
  const map = new Map()  // 字符 → 最近出现的索引
  let left = 0, maxLen = 0

  for (let right = 0; right < s.length; right++) {
    const char = s[right]
    // 若字符在窗口内出现过，移动左指针到重复字符的下一位
    if (map.has(char) && map.get(char) >= left) {
      left = map.get(char) + 1
    }
    map.set(char, right)  // 更新字符最新位置
    maxLen = Math.max(maxLen, right - left + 1)
  }
  return maxLen
};
```

**⚠️ 易错点：**
- `map.get(char) >= left` 是必要条件：Map 中存的是历史位置，可能已经在窗口外了
- left 只向右移，不能向左（`left = map.get(char) + 1` 可能比 left 小时不更新）
- 窗口长度是 `right - left + 1`（包含两端）

### No.5 · 最大子数组和（动态规划） 

> 给你一个整数数组 `nums`，找出具有最大和的连续子数组（至少包含一个元素），返回其最大和。

**示例：**
```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6（子数组 [4,-1,2,1]）
```

**解题思路（DP）：**
1. 定义 `dp[i]` = 以 `nums[i]` 结尾的连续子数组的最大和
2. 状态转移：`dp[i] = Math.max(dp[i-1] + nums[i], nums[i])`
   - 若 `dp[i-1] > 0`，延续前面的子数组更优
   - 若 `dp[i-1] <= 0`，从 `nums[i]` 重新开始
3. 遍历过程中维护全局最大值
4. 时间复杂度：O(n)；空间复杂度：O(n)

```js
var maxSubArray = function(nums) {
  const dp = new Array(nums.length).fill(0)
  dp[0] = nums[0]       // 以第一个元素结尾，最大和就是它本身
  let max = nums[0]     // 全局最大值，初始化为 dp[0]

  for (let i = 1; i < nums.length; i++) {
    // dp[i]：以 nums[i] 结尾的连续子数组最大和
    dp[i] = Math.max(dp[i - 1] + nums[i], nums[i])
    max = Math.max(max, dp[i])  // 更新全局最大值
  }
  return max
};
```

**空间优化（Kadane 算法）：**

`dp[i]` 只依赖 `dp[i-1]`，可以用滚动变量代替数组，空间降至 O(1)：

```js
var maxSubArray = function(nums) {
  let prev = nums[0]    // 相当于 dp[i-1]
  let max = nums[0]

  for (let i = 1; i < nums.length; i++) {
    prev = Math.max(prev + nums[i], nums[i])
    max = Math.max(max, prev)
  }
  return max
};
```

**⚠️ 易错点：**
- `dp[0]` 和 `max` 都初始化为 `nums[0]`，不能是 0（全负数时会答错）
- 状态转移的含义：`dp[i-1] <= 0` 时"断开"重新从 `nums[i]` 开始更优
- 最终答案是遍历过程中维护的 `max`，不是 `dp[n-1]`（最优子数组不一定以最后元素结尾）
- 空间优化后就是经典 Kadane 算法，面试时两种写法都要能说清楚

### No.6 · 有效括号 

> 给定只包含 `'('`, `')'`, `'{'`, `'}'`, `'['`, `']'` 的字符串，判断是否有效（左括号必须用相同类型右括号关闭，且按正确顺序）。

**示例：**
```
输入：s = "()[]{}"  → 输出：true
输入：s = "([)]"    → 输出：false
```

**解题思路（栈）：**
1. 遇到左括号压栈
2. 遇到右括号，检查栈顶是否为对应左括号
3. 最后栈为空则合法
4. 时间复杂度：O(n)；空间复杂度：O(n)

```js
var isValid = function(s) {
  const stack = []
  const map = { ')': '(', '}': '{', ']': '[' }  // 右括号 → 对应左括号

  for (const char of s) {
    if (!map[char]) {
      stack.push(char)  // 左括号直接压栈
    } else {
      // 右括号：栈顶必须是对应的左括号
      if (stack.pop() !== map[char]) return false
    }
  }
  return stack.length === 0  // 栈为空才完全匹配
};
```

**⚠️ 易错点：**
- 栈为空时 `stack.pop()` 返回 undefined，`undefined !== '('` 会正确返回 false
- 最后必须检查 `stack.length === 0`（可能剩余未闭合的左括号）
- map 的方向是"右括号→左括号"，不要反过来

### No.7 · 二叉树层序遍历 

> 给你二叉树的根节点 `root`，返回其节点值的层序遍历（逐层从左到右）。

**示例：**
```
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]
```

**解题思路（BFS）：**
1. 用队列存储每一层的节点
2. 每次处理一整层，记录当前层的长度
3. 时间复杂度：O(n)；空间复杂度：O(n)

```js
var levelOrder = function(root) {
  if (!root) return []
  const result = []
  const queue = [root]

  while (queue.length) {
    const levelSize = queue.length  // 当前层的节点数
    const level = []

    while(levelSize--)
      const node = queue.shift()
      level.push(node.val)
      if (node.left) queue.push(node.left)
      if (node.right) queue.push(node.right)
    }
    result.push(level)
  }
  return result
};
```

**⚠️ 易错点：**
- 必须在循环开始时记录 `levelSize = queue.length`，循环中 queue 会变化
- 返回的是二维数组 `[[...], [...]]`，不是一维
- `queue.shift()` 是 O(n)，大数据量时可用双端队列优化

### No.8 · 接雨水 

> 给定 n 个非负整数表示每个宽度为 1 的柱子的高度，计算按此排列的柱子能接多少雨水。

**示例：**
```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
```

**解题思路（双指针）：**
1. 左右指针，维护左最大高度 leftMax 和右最大高度 rightMax
2. 哪边更小，哪边的积水就已确定（由另一边的最大高度限制）
3. 时间复杂度：O(n)；空间复杂度：O(1)

```js
var trap = function(height) {
  let left = 0, right = height.length - 1
  let leftMax = 0, rightMax = 0
  let water = 0

  while (left < right) {
    leftMax = Math.max(leftMax, height[left])
    rightMax = Math.max(rightMax, height[right])

    if (leftMax < rightMax) {
      // 左边是短板，当前位置积水 = leftMax - height[left]
      water += leftMax - height[left]
      left++
    } else {
      // 右边是短板，当前位置积水 = rightMax - height[right]
      water += rightMax - height[right]
      right--
    }
  }
  return water
};
```

**⚠️ 易错点：**
- 先更新 leftMax/rightMax，再计算积水（用更新后的值）
- 积水不会为负（leftMax >= height[left] 恒成立）
- 双指针法要理解"短板决定积水量"的贪心逻辑

### No.9 · 爬楼梯 

> 爬 n 阶楼梯，每次可以爬 1 或 2 个台阶，有多少种方法？

**示例：**
```
输入：n = 4
输出：5（1+1+1+1, 1+1+2, 1+2+1, 2+1+1, 2+2）
```

**解题思路：**
1. f(n) = f(n-1) + f(n-2)，斐波那契数列
2. 滚动数组优化空间为 O(1)
3. 时间复杂度：O(n)；空间复杂度：O(1)

```js
var climbStairs = function(n) {
  if (n <= 2) return n
  let prev = 1, curr = 2

  for (let i = 3; i <= n; i++) {
    const next = prev + curr  // f(i) = f(i-1) + f(i-2)
    prev = curr
    curr = next
  }
  return curr
};
```

**⚠️ 易错点：**
- f(1)=1, f(2)=2（不是 f(2)=1），初始值容易搞混
- 循环从 3 开始到 n
- 空间优化时用滚动变量，不要保存整个 dp 数组

### No.10 · 零钱兑换 

> 给你一个整数数组 `coins`（各面额硬币）和总金额 `amount`，计算凑成 amount 所需最少硬币数，无法凑成返回 -1。

**示例：**
```
输入：coins = [1,2,5], amount = 11
输出：3（5+5+1）
```

**解题思路（完全背包 DP）：**
1. `dp[i]` = 凑成金额 i 所需最少硬币数
2. `dp[i] = min(dp[i], dp[i - coin] + 1)` for each coin
3. 初始化 `dp[0] = 0`，其余为 Infinity
4. 时间复杂度：O(amount × n)；空间复杂度：O(amount)

```js
var coinChange = function(coins, amount) {
  const dp = new Array(amount + 1).fill(Infinity)
  dp[0] = 0  // 凑成 0 需要 0 个硬币

  for (let i = 1; i <= amount; i++) {
    for (const coin of coins) {
      if (coin <= i && dp[i - coin] !== Infinity) {
        dp[i] = Math.min(dp[i], dp[i - coin] + 1)
      }
    }
  }
  return dp[amount] === Infinity ? -1 : dp[amount]
};
```

**⚠️ 易错点：**
- 初始化用 `Infinity` 而非 -1 或 0（方便做 min 比较）
- 最后返回时判断是否仍为 Infinity，是则返回 -1
- 完全背包：内层循环是硬币，不需要倒序（每枚硬币可用多次）

### No.11 · 最长回文子串 

> 给你一个字符串 `s`，找到 `s` 中最长的回文子串。

**示例：**
```
输入：s = "babad"
输出："bab"（或 "aba"）
```

**解题思路（中心扩展）：**
1. 枚举每个字符作为中心（奇数：单字符；偶数：两字符）
2. 向两边扩展，直到不相等
3. 时间复杂度：O(n²)；空间复杂度：O(1)

```js
var longestPalindrome = function(s) {
  let start = 0, maxLen = 1

  function expand(left, right) {
    // 向两边扩展，直到超界或不等
    while (left >= 0 && right < s.length && s[left] === s[right]) {
      if (right - left + 1 > maxLen) {
        maxLen = right - left + 1
        start = left
      }
      left--
      right++
    }
  }

  for (let i = 0; i < s.length; i++) {
    expand(i, i)      // 奇数长度，以 i 为中心
    expand(i, i + 1)  // 偶数长度，以 i 和 i+1 为中心
  }
  return s.slice(start, start + maxLen)
};
```

**⚠️ 易错点：**
- 必须同时处理奇偶两种情况

### No.12 · 三数之和 

> 给你一个整数数组 `nums`，判断是否存在三元组 `[a,b,c]` 使得 `a+b+c=0`，返回所有不重复的三元组。

**示例：**
```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

**解题思路（排序 + 双指针）：**
1. 排序后，固定第一个数 nums[i]
2. 在 i 右边用双指针找另外两个数
3. 去重：跳过相邻相同的元素
4. 时间复杂度：O(n²)；空间复杂度：O(1)

```js
var threeSum = function(nums) {
  nums.sort((a, b) => a - b)
  const result = []

  for (let i = 0; i < nums.length - 2; i++) {
    if (nums[i] > 0) break  // 最小的都大于 0，不可能为 0

    // 跳过重复的第一个数
    if (i > 0 && nums[i] === nums[i - 1]) continue

    let left = i + 1, right = nums.length - 1

    while (left < right) {
      const sum = nums[i] + nums[left] + nums[right]
      if (sum === 0) {
        result.push([nums[i], nums[left], nums[right]])
        // 跳过重复的左右指针
        while (left < right && nums[left] === nums[left + 1]) left++
        while (left < right && nums[right] === nums[right - 1]) right--
        left++
        right--
      } else if (sum < 0) {
        left++
      } else {
        right--
      }
    }
  }
  return result
};
```

**⚠️ 易错点：**
- 去重逻辑：i 的去重用 `i > 0 && nums[i] === nums[i-1]`；left/right 的去重在找到答案后跳过
- 找到答案后必须同时移动 left++ 和 right--，不能只移动一个
- `nums[i] > 0` 时可以提前 break（排序后后面的更大）


1. 用虚拟头节点 dummy 简化边界处理
2. 找到 left 的前驱节点 pre
3. 从 pre.next 开始，头插法反转 right - left 次
4. 时间复杂度：O(n)；空间复杂度：O(1)

```js
  // 移动到 left 的前驱位置
  for (let i = 0; i < left - 1; i++) pre = pre.next

  for (let i = 0; i < right - left; i++) {
```

- 必须先 `curr.next = next.next` 再操作 `next`，顺序不能颠倒

### No.21 · 数组中第 K 大的元素 

> 给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素（不是第 k 个不同的元素）。

**示例：**
```
输入：nums = [3,2,1,5,6,4], k = 2
输出：5
```

**解题思路（快速选择）：**
1. 类似快排的分区，每次确定 pivot 的最终位置
2. 若 pivot 位置 = n-k，直接返回（第 k 大 = 从右数第 k 个）
3. 若 pivot 位置 > n-k，在左半部分继续找
4. 若 pivot 位置 < n-k，在右半部分继续找
5. 平均时间复杂度：O(n)；最坏 O(n²)

```js
var findKthLargest = function(nums, k) {
  const target = nums.length - k  // 第 k 大 = 升序排列第 target 个（下标）

  function quickSelect(left, right) {
    if (left === right) return nums[left]

    const pivotIndex = partition(left, right)
    if (pivotIndex === target) return nums[pivotIndex]
    if (pivotIndex > target) return quickSelect(left, pivotIndex - 1)
    return quickSelect(pivotIndex + 1, right)
  }

  function partition(left, right) {
    const pivot = nums[right]
    let i = left - 1
    for (let j = left; j < right; j++) {
      if (nums[j] <= pivot) {
        i++
        ;[nums[i], nums[j]] = [nums[j], nums[i]]
      }
    }
    ;[nums[i + 1], nums[right]] = [nums[right], nums[i + 1]]
    return i + 1
  }

  return quickSelect(0, nums.length - 1)
};
```

**⚠️ 易错点：**
- 第 k 大对应升序数组的下标是 `n - k`，不是 `k - 1`
- 快速选择平均 O(n) 但最坏 O(n²)，面试时可提堆解法（O(n log k)）作对比
- 递归终止条件 `left === right` 时直接返回，不需要再分区

### No.22 · 最长公共子序列 

> 给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长公共子序列的长度（不要求连续）。

**示例：**
```
输入：text1 = "abcde", text2 = "ace"
输出：3（"ace"）
```

**解题思路（二维 DP）：**
1. `dp[i][j]` = text1 前 i 个字符与 text2 前 j 个字符的 LCS 长度
2. 若 `text1[i-1] === text2[j-1]`，`dp[i][j] = dp[i-1][j-1] + 1`
3. 否则 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
4. 时间复杂度：O(m×n)；空间复杂度：O(m×n)

```js
var longestCommonSubsequence = function(text1, text2) {

  // dp[i][j] 表示 text1[0..i-1] 和 text2[0..j-1] 的 LCS 长度
  const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0))

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (text1[i - 1] === text2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1  // 字符匹配，长度 +1
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1])  // 取较长的
      }
    }
  }
  return dp[m][n]
};
```

**⚠️ 易错点：**
- 下标 i、j 从 1 开始，访问字符用 `text1[i-1]`（偏移 1）
- dp 数组大小是 `(m+1) × (n+1)`，第 0 行第 0 列作为空字符串边界（值为 0）
- 区分 LCS（不连续）和最长公共子串（连续，需要 `dp[i][j] = dp[i-1][j-1]+1` 且不匹配时置 0）

```js
    dfs(r, c - 1)
  }

```

3. 队首超出窗口则移除
4. 时间复杂度：O(n)；空间复杂度：O(k)

```js
var maxSlidingWindow = function(nums, k) {

  const result = []
```

### No.28 · 环形链表 II 

> 给定一个链表的头节点 `head`，返回链表开始入环的第一个节点，如果无环则返回 null。

**示例：**
```
输入：head = [3,2,0,-4]，tail 连到下标 1
输出：节点 2（下标 1）
```

**解题思路（数学推导）：**
1. 快慢指针相遇后，将慢指针重置到 head
2. 快慢指针同速前进（每次 1 步），再次相遇点即为环的入口
3. 推导：设 head 到入口距离 a，环长 b，相遇时慢指针走了 a+c，快指针走了 a+c+nb。快 = 2×慢 → nb = a+c → a = nb-c。重置慢指针后同步走 a 步，快指针从相遇点走 nb-c 步也到入口。
4. 时间复杂度：O(n)；空间复杂度：O(1)

```js
var detectCycle = function(head) {
  let slow = head, fast = head

  // 第一阶段：找相遇点
  while (fast && fast.next) {
    slow = slow.next
    fast = fast.next.next
    if (slow === fast) {
      // 第二阶段：找环入口
      slow = head  // 重置慢指针到 head
      while (slow !== fast) {
        slow = slow.next
        fast = fast.next  // 两者都走 1 步
      }
      return slow  // 再次相遇即为环入口
    }
  }
  return null  // 无环
};
```

**⚠️ 易错点：**
- 找到相遇点后，`fast` 不动，只把 `slow` 重置到 head
- 第二阶段两者都走 1 步（不是快走 2 步）
- 一定要先完成相遇检测，再做第二阶段，不能混在一起

### No.30 · 课程表（拓扑排序） 

> 有 numCourses 门课程，prerequisites[i] = [a, b] 表示学 a 前必须先学 b。判断是否能完成所有课程学习（即有无循环依赖）。

**示例：**
```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true（先学 0 再学 1）

输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false（循环依赖）
```

**解题思路（拓扑排序 BFS / Kahn 算法）：**
1. 构建邻接表和每个节点的入度
2. 将入度为 0 的节点加入队列
3. BFS 依次处理，每处理一个节点，其邻居入度 -1；若入度变为 0 则入队
4. 若最终处理节点数等于总课程数，则无环
5. 时间复杂度：O(V+E)；空间复杂度：O(V+E)

```js
var canFinish = function(numCourses, prerequisites) {
  const inDegree = new Array(numCourses).fill(0)  // 每个节点的入度
  const graph = Array.from({ length: numCourses }, () => [])  // 邻接表

  for (const [a, b] of prerequisites) {
    graph[b].push(a)  // b → a（学完 b 才能学 a）
    inDegree[a]++
  }

  // 将所有入度为 0 的课程加入队列（可以直接开始学的）
  const queue = []
  for (let i = 0; i < numCourses; i++) {
    if (inDegree[i] === 0) queue.push(i)
  }

  let count = 0  // 已完成的课程数
  while (queue.length) {
    const course = queue.shift()
    count++
    for (const next of graph[course]) {
      inDegree[next]--
      if (inDegree[next] === 0) queue.push(next)
    }
  }
  return count === numCourses  // 全部完成则无环
};
```

**⚠️ 易错点：**
- 边的方向：`prerequisites[i] = [a, b]` 是 b 指向 a，`graph[b].push(a)`
- 判断无环：`count === numCourses`（若有环，环中节点入度永远不会降到 0）
- 初始化时入度为 0 的节点可能不止一个，要全部入队

### No.31 · 编辑距离 

> 给你两个单词 `word1` 和 `word2`，返回将 `word1` 转换成 `word2` 所需的最少操作数（插入/删除/替换各算 1 次）。

**示例：**
```
输入：word1 = "horse", word2 = "ros"
输出：3（horse → rorse → rose → ros）
```

**解题思路（二维 DP）：**
1. `dp[i][j]` = word1 前 i 个字符变成 word2 前 j 个字符的最少操作数
2. 字符相同：`dp[i][j] = dp[i-1][j-1]`
3. 字符不同：`dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])`（删/插/替换）
4. 时间复杂度：O(m×n)；空间复杂度：O(m×n)

```js
var minDistance = function(word1, word2) {
  const m = word1.length, n = word2.length
  const dp = Array.from({ length: m + 1 }, (_, i) =>
    new Array(n + 1).fill(0).map((_, j) => i || j)  // 边界：dp[i][0]=i, dp[0][j]=j
  )

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (word1[i - 1] === word2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1]  // 字符相同，不需要操作
      } else {
        dp[i][j] = 1 + Math.min(
          dp[i - 1][j],    // 删除 word1[i-1]
          dp[i][j - 1],    // 插入 word2[j-1]
          dp[i - 1][j - 1] // 替换
        )
      }
    }
  }
  return dp[m][n]
};
```

**⚠️ 易错点：**
- 边界条件：`dp[i][0] = i`（word1 前 i 个字符删到空需 i 次），`dp[0][j] = j`
- 三种操作对应三个方向：删(↑)、插(←)、替换(↖)
- 初始化写法较繁琐，建议分开两次循环初始化边界再填表

```
输出："BANC"
```

2. 右指针扩大窗口，满足条件后左指针收缩求最小
3. 时间复杂度：O(m+n)；空间复杂度：O(n)

```js
  for (const c of t) need.set(c, (need.get(c) || 0) + 1)

  let left = 0, valid = 0  // valid: 已满足的字符种类数
  let minStart = 0, minLen = Infinity
  const window = new Map()

  for (let right = 0; right < s.length; right++) {
    const c = s[right]
    window.set(c, (window.get(c) || 0) + 1)
    // 若该字符是 t 中需要的，且数量恰好满足，valid++
    if (need.has(c) && window.get(c) === need.get(c)) valid++

        minLen = right - left + 1
        minStart = left
      }
      const d = s[left++]
      if (need.has(d)) {
        if (window.get(d) === need.get(d)) valid--  // 移除后不再满足
        window.set(d, window.get(d) - 1)
      }
    }
  }
  return minLen === Infinity ? '' : s.slice(minStart, minStart + minLen)
};
```

- `valid` 记录的是"字符种类"满足数，不是总字符数（重复字符只算一次）
- 收缩左边界时，先判断 valid 是否减少，再更新 window（判断用的是更新前的值）

```js
  const result = [intervals[0]]

  for (let i = 1; i < intervals.length; i++) {

    const curr = intervals[i]

    if (curr[0] <= last[1]) {
      // 重叠：更新终点为两者较大值
      last[1] = Math.max(last[1], curr[1])
    } else {
      // 不重叠：直接加入
      result.push(curr)
    }
  }
  return result
};
```

**⚠️ 易错点：**
- 合并时终点取 `Math.max`，不能直接用 `curr[1]`（curr 可能被完全包含）
- 排序按 `a[0] - b[0]`，不要写成 `a - b`
- 初始化 result 为 `[intervals[0]]`，循环从 1 开始

### No.37 · 最小栈 

> 设计一个支持 push、pop、top 操作，并能在 O(1) 时间内检索最小元素的栈。

**示例：**
```
MinStack()
push(-2), push(0), push(-3)
getMin() → -3
pop()
top()    → 0
getMin() → -2
```

**解题思路（辅助栈）：**
1. 主栈正常操作
2. 辅助栈同步维护，每次 push 时存入当前最小值
3. 时间复杂度：所有操作 O(1)；空间复杂度：O(n)

```js
class MinStack {
  constructor() {
    this.stack = []
    this.minStack = []  // 辅助栈，栈顶始终是当前最小值
  }

  push(val) {
    this.stack.push(val)
    // 辅助栈取当前最小值（和新值比较）
    const min = this.minStack.length
      ? Math.min(val, this.minStack[this.minStack.length - 1])
      : val
    this.minStack.push(min)
  }

  pop() {
    this.stack.pop()
    this.minStack.pop()  // 同步弹出
  }

  top() {
    return this.stack[this.stack.length - 1]
  }

  getMin() {
    return this.minStack[this.minStack.length - 1]
  }
}
```

**⚠️ 易错点：**
- 辅助栈每次都要 push（和主栈等长），不能只在更新最小值时 push
- pop 时两个栈同步弹出
- 辅助栈存的是"当前状态下的全局最小值"，不是"该层自己的值"

### No.38 · 手写快速排序 

> 实现快速排序算法，对整数数组进行原地升序排序。

**示例：**
```
输入：[3, 1, 4, 1, 5, 9, 2, 6]
输出：[1, 1, 2, 3, 4, 5, 6, 9]
```

**解题思路：**
1. 选取基准值（pivot），通常取最后一个元素
2. 分区：将小于 pivot 的元素移到左边，大于的移到右边
3. 递归对左右两个子数组做同样操作
4. 时间复杂度：平均 O(n log n)，最坏 O(n²)；空间复杂度：O(log n)

```js
function quickSort(arr, left = 0, right = arr.length - 1) {
  if (left >= right) return arr  // 递归终止条件

  const pivotIndex = partition(arr, left, right)
  quickSort(arr, left, pivotIndex - 1)   // 递归排左半部分
  quickSort(arr, pivotIndex + 1, right)  // 递归排右半部分
  return arr
}

function partition(arr, left, right) {
  const pivot = arr[right]  // 选最右边作为基准
  let i = left - 1          // i 指向小于 pivot 区域的右边界

  for (let j = left; j < right; j++) {
    if (arr[j] <= pivot) {
      i++
      // 将小于 pivot 的元素交换到左边
      ;[arr[i], arr[j]] = [arr[j], arr[i]]
    }
  }
  // 将 pivot 放到最终位置
  ;[arr[i + 1], arr[right]] = [arr[right], arr[i + 1]]
  return i + 1  // 返回 pivot 的最终索引
}
```

**⚠️ 易错点：**
- 递归终止条件是 `left >= right`，不是 `left > right`（等于时只有一个元素，无需排序）
- 最坏情况：数组已排序时每次选末尾为 pivot，退化为 O(n²)；优化：随机选 pivot 或三数取中
- 交换用解构赋值时注意加分号 `;[a, b] = [b, a]`，否则可能被 ASI 误解析

### No.39 · 手写归并排序 

> 实现归并排序，稳定排序，时间复杂度 O(n log n)。

**示例：**
```
输入：[5, 2, 8, 1, 9, 3]
输出：[1, 2, 3, 5, 8, 9]
```

**解题思路：**
1. 分：递归将数组从中间一分为二
2. 治：递归排序左右两半
3. 合：合并两个有序数组
4. 时间复杂度：O(n log n)；空间复杂度：O(n)（需要额外数组）

```js
function mergeSort(arr) {
  if (arr.length <= 1) return arr  // 单个元素直接返回

  const mid = Math.floor(arr.length / 2)
  const left = mergeSort(arr.slice(0, mid))   // 递归排序左半
  const right = mergeSort(arr.slice(mid))     // 递归排序右半
  return merge(left, right)
}

function merge(left, right) {
  const result = []
  let i = 0, j = 0

  // 依次比较两个数组的头部，取较小的放入结果
  while (i < left.length && j < right.length) {
    if (left[i] <= right[j]) {
      result.push(left[i++])
    } else {
      result.push(right[j++])
    }
  }
  // 将剩余部分追加（只有一个数组还有剩余）
  return result.concat(left.slice(i)).concat(right.slice(j))
}
```

**⚠️ 易错点：**
- `merge` 中用 `<=` 保证稳定性（相等时取左边先），不能用 `<`
- `slice` 是左闭右开：`arr.slice(0, mid)` 不包含 `arr[mid]`
- 归并排序需要 O(n) 额外空间，面试时要主动说出这个代价
